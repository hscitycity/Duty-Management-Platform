### 정제본 사용 시 주의
- PDF 텍스트 추출본을 파싱한 것이라 일부 부서명·문구에 띄어쓰기 오류가 있을 수 있다. 배정 근거로 화면에 표시할 때는 원문 확인을 권한다.
- **사무위임 규칙에 읍면동 도로보수 권한은 없다.** 별표 2의 도로과 사무는 접도구역 불법행위 단속 두 건뿐이다. 매송면 도로보수 같은 실무는 내부 지침·예산 배정 영역이므로, 법적 소관(도로과)과 처리 주체(읍면동)를 분리해 표시한다.
- 마을도로 판정용 shp와 소규모 보수 경계 기준은 사용자 제공 대기 중.

## 여는 방법
HTML은 모두 단일 파일이라 더블클릭하면 열린다. 인터넷 연결 시 폰트가 적용된다.

## 커밋 예시
```bash
mkdir -p docs/규정자료
# 파일들을 위 구분대로 옮긴 뒤
git add CLAUDE.md ClaudeCode_작업지시서.md docs/
git commit -m "설계 자료·작업 지시서·규정 근거 추가"
git push
```
