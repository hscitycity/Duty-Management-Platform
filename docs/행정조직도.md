## 0. 명칭 규칙 【시스템 반영 필요】

**읍사무소·면사무소·동주민센터 표기를 전부 「행정복지센터」로 바꾼다.**

| 구분 | 잘못된 표기 | 올바른 표기 |
|---|---|---|
| 읍 | 향남읍사무소 | **향남읍행정복지센터** |
| 면 | 매송면사무소 | **매송면행정복지센터** |
| 동 | 병점1동주민센터 | **병점1동행정복지센터** |

- 붙여 쓴다(`매송면행정복지센터`). 줄바꿈이 필요한 좁은 화면에서는 `매송면\n행정복지센터`로 끊는다.
- 짧게 줄여야 하는 목록·배지에서는 **`매송면`**만 쓴다. `매송면사무소`처럼 잘못된 축약을 만들지 않는다.
- 기관장 호칭은 그대로 **읍장·면장·동장**이다. 「행정복지센터장」이 아니다.

**수정 대상**: 담당부서 배정 결과, 결과보고 처리 주체, 읍면동 결과보고 화면 헤더, 문자 인계 발신 기관명, 시민 안내 문구, 시나리오 데이터.

## 5. 민원 배정에 쓰는 계층

민원 하나에 **세 층**이 걸린다. 화면에는 소관과 처리 주체를 나눠 표시한다.

| 층 | 예시 | 근거 |
|---|---|---|
| **본청 소관** | 도로과 | 조례 별표 8 분장사무 |
| **구청 소관** | 만세구청 안전건설과 | 구청 사무분장 |
| **처리 주체** | 향남읍행정복지센터 | 소규모 현장처리 기준(내부 지침) |

### 도로·교통 민원 배정 참고

| 상황 | 소관 |
|---|---|
| 시도·국도·지방도 유지보수 | 안전건설실 **도로과** |
| 마을도로·이면도로 소규모 보수 | 해당 **읍면동행정복지센터** (구청 안전건설과 경유) |
| 신호·교통체계 개선 | 교통국 **교통정책과** (경찰 협의) |
| 버스정류장·대중교통 | 교통국 **대중교통과** |
| 불법주정차·주차시설 | 교통국 **주차물류과** |
| 도로 침수·하수 역류 | **맑은물사업소 하수과** |
| 가로수·공원시설 | **공원녹지사업소** (서부·동부 관리과) |
| 동물사체 | 농정해양국 **동물보호과** 또는 구청 환경 부서 |
| 무단투기·소음·악취 | 기후에너지환경국 **환경지도과**, 구청 환경관리과·경제환경과·도시환경과 |
| 재난 상황 총괄 | 안전건설실 **재난대응과** |

**주의**: 구청마다 환경 담당 부서명이 다르다(만세=환경관리과, 효행·병점=경제환경과, 동탄=도시환경과). 배정 로직에서 구별로 매핑해야 한다.

## 6. 시스템 반영 항목

1. **명칭 일괄 변경** — 읍사무소·면사무소·동주민센터 → 행정복지센터 (0장)
2. **구청 계층 추가** — 현재 배정이 본청·읍면동 2층인데, 구청 안전건설과가 빠져 있다. 도로·안전 민원의 실제 경유지다
3. **구별 환경부서 매핑** — 구마다 명칭이 달라 단일 매핑으로는 틀린다
4. **사업소 배정** — 하수(맑은물사업소)·가로수(공원녹지사업소)는 본청 과가 아니라 사업소 소관이다. 분장사무 데이터에 사업소가 포함돼 있는지 확인 필요
5. **보건소 4개소** — 감염병·방역 민원 대비
6. **청사 위치 표시** — 배정 결과에 소재 청사를 함께 노출한다. 야간에 "도로과 · 본청"과 "대중교통과 · AI혁신센터"는 연락·이송 판단이 다르다. 좌표를 넣으면 지도에 청사 마커도 가능

## 7. 확인 필요

- 부서명 뒤 낱글자는 **청사 위치 표시**다(4-1장에 반영). 순서대로 대응시켰으므로 실제와 대조 바람.
- **근로자종합복지관·평생학습관**은 청사 목록에는 있으나 배정된 부서가 조직도에 나타나지 않았다. 확인 필요.
- 청사별 주소·좌표가 확보되면 지도 마커로 표시할 수 있다.
- 조직 개편이 잦으므로 **개정일 기준**을 문서 상단에 기록하는 운용이 필요하다. 현재 문서는 제공받은 조직도 기준.
