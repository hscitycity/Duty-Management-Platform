설계 인스펙터— 화면 데이터 AI 자동화 점검

화면을 읽지 못했습니다

이 인스펙터는 실제 index.html 을 그대로 띄워 그 위에 개발요소를 표시합니다. 정적 복사본이 아니라서 화면이 바뀌어도 어긋나지 않습니다.
다만 브라우저가 file:// 로 열린 문서끼리는 서로 읽지 못하게 막습니다.

이렇게 열어 주세요

  1. 저장소 폴더에서 npx serve . 또는 python -m http.server 실행
  2. 브라우저에서 http://localhost:3000/docs/설계인스펙터.html 접속
  3. 배포본에서 보려면 /docs/설계인스펙터.html 로 접속

화면 없이 목록만 보려면 상단 목록 보기를 누르세요 — 그건 언제나 됩니다.
