# 항목번호.md — 화면 요소 번호표

> **수정 요청은 이 번호로 부른다.** 예) "C-4 버튼 색 바꿔", "F-2 팝업에 근무대 추가"

## 번호 표시 방법

`Ctrl+Shift+N` — 해당 요소 왼쪽 위에 노란 번호표가 붙는다. 다시 누르면 사라진다.
번호는 `data-no="C-4"` 속성으로 코드에 박혀 있으므로, 요소를 옮겨도 번호는 따라간다.
