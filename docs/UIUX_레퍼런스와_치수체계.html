UI/UX 레퍼런스와 치수 체계

화면마다 버튼 높이와 여백이 조금씩 다른 문제는 감각이 아니라 기준이 없어서 생깁니다. 참고할 곳과, 이 플랫폼에 적용할 구체적 수치를 정리했습니다.

공공 표준앱 기본기상황판·데이터 적용 치수고칠 지점

1. 공공 서비스 표준

행안부 제안까지 염두에 두면, 이 계열은 참고가 아니라 근거가 됩니다.

KRDS — 대한민국 정부 디자인 시스템
krds.go.kr · 행정안전부

행정안전부가 배포한 디지털 정부서비스 UI/UX 가이드라인. 색·타이포·간격을 코드값(디자인 토큰)으로 정의하고 컴포넌트 키트까지 제공합니다. 2023년 전자정부 이용 실태조사에서 나온 “표현이 일관되지 않아 쓰기 어렵다”는 지적이 출발점이었습니다.

가져올 것 · 토큰 이름과 수치 체계를 그대로 채택. 행안부 과제 제안서에 “KRDS 준수”를 명시하면 심사 관점에서 가장 강한 한 줄이 됩니다. 무료·공식이라 채택 비용도 없습니다.
GOV.UK Design System
design-system.service.gov.uk

영국 정부 표준. 화려함을 버리고 “한 화면에 한 가지 질문”을 원칙으로 삼습니다. 오류 메시지·양식·단계별 진행 화면의 문안까지 규정돼 있습니다.

가져올 것 · 시민 신고 3단계 위저드의 단계 표시와 오류 문안 방식
U.S. Web Design System (USWDS)
designsystem.digital.gov

미국 연방 표준. 8px 간격 체계와 접근성 검사 기준이 문서·코드로 함께 배포됩니다. 재난 관련 정부 사이트 다수가 이 위에 올라가 있습니다.

가져올 것 · 간격 체계와 대비·초점 표시 검사 기준

2. 앱 기본기 — 크기와 터치

“크기가 안 맞는다”는 문제를 직접 푸는 문서들입니다.

Material Design 3
m3.material.io

구글 표준. 4px 배수 간격, 타입 스케일 15단계, 터치 영역 최소 48×48, 하단 시트·스낵바 같은 모바일 패턴이 수치와 함께 정의돼 있습니다. 배민을 포함한 국내 앱 다수가 이 체계 위에 있습니다.

가져올 것 · 4·8px 배수 규칙, 터치 48px, 하단 시트 구조 — 시민 창구 재설계의 뼈대
Apple Human Interface Guidelines
developer.apple.com/design

터치 영역 최소 44pt, 안전 영역(노치·홈 인디케이터) 처리, 한 손 조작을 위한 하단 배치 원칙.

가져올 것 · 아이폰에서 하단 버튼이 잘리지 않는 안전 영역 처리
8-Point Grid System
spec.fm / 디자인 커뮤니티 통용 규칙

모든 여백·크기를 8의 배수(작은 값은 4)로만 쓰는 규칙. 값을 고민하지 않게 되고, 화면이 저절로 정렬됩니다. 지금처럼 여백이 7·9·13px씩 섞이는 상태를 없애는 가장 빠른 방법입니다.

가져올 것 · 간격 후보를 4·8·12·16·24·32·48 일곱 개로 제한
Nielsen Norman Group — 사용성 원칙
nngroup.com

시스템 상태 가시성, 사용자 언어, 오류 예방 등 10가지 원칙. 배민 주문추적이 왜 안심을 주는지를 설명하는 이론적 근거(상태 가시성)이기도 합니다.

가져올 것 · 처리 추적 화면의 설계 논리, 발표 답변 근거

3. 상황판·데이터 화면

정보 밀도가 높은 화면은 일반 웹과 규칙이 다릅니다.

IBM Carbon Design System
carbondesignsystem.com

업무용·관제용 화면에 특화된 체계. 좁은 행 높이, 표·지표 카드, 다중 패널 배치 규칙이 정의돼 있습니다. 지금 상황판처럼 3열에 정보를 빽빽하게 담는 화면의 정석입니다.

가져올 것 · 좌·중·우 3열 폭 비율, 카드 안쪽 여백, 표 행 높이
Ant Design
ant.design

관리자 화면 컴포넌트가 가장 촘촘한 체계. 목록·필터·상태 배지·빈 화면 처리까지 사례가 많습니다.

가져올 것 · 상태 배지 색 규칙, 목록 필터 배치
Grafana / 관제 대시보드 패턴
grafana.com

지표를 크게, 그래프는 작게, 시간 범위 선택을 상단 고정. 야간 근무를 전제한 어두운 화면 배색 기준도 참고할 만합니다.

가져올 것 · 대시보드 지표 카드 크기 위계, 야간모드 배색
Esri ArcGIS 재난대응 화면
esri.com — Emergency Response

지도가 중심이고 정보 패널이 접히는 상황실 표준 배치. 지도 위 도구 모음을 어디에 두는지가 잘 정리돼 있습니다.

가져올 것 · 지도 위 레이어 도구 배치와 접기 방식

🚨 민원 🎪 행사·인파 📐 지적

높이를 고정하고 좌우 여백만 12px로 통일합니다.

요소손볼 내용
UI-D-M2레이어 버튼 20개 — 높이 36px 고정, 좌우 여백 12px, 줄 간격 8px
UI-C3시민 창구 유형 버튼 — 최소 48px, 타일 형태로 두 칸 배치
UI-D-L*좌측 카드 7종 — 안쪽 여백 16px, 카드 사이 24px로 통일
UI-B1대시보드 지표 카드 — 숫자 30px, 설명 12px로 위계 분리
UI-C1모바일 하단 버튼 — 안전 영역 처리로 홈 인디케이터에 가리지 않게
전체여백을 위 일곱 값으로만 교체 — 7·9·13·18px 같은 값 제거
순서를 권한다면 치수 값을 먼저 한곳에 정의하고, 화면을 하나씩 그 값으로 바꾸는 방식입니다. 한 번에 전부 바꾸면 무엇이 틀어졌는지 확인이 어렵습니다.
