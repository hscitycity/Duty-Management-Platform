# 기동단_사양서.md

교통·도로민원 신속처리 기동단 작업판(`#road`) 사양

> 운영 개시 **2026. 9. 7.** · 대표전화 **1833-4088**
> 현재 구현은 처리기한·유형·절차가 실제 업무와 다르다. 이 문서 기준으로 교체한다.

---

## 0. 명칭

**정식 명칭은 「교통·도로민원 신속처리 기동단」이다.**

| 위치 | 표기 |
|---|---|
| 화면 제목·문서·제안서 | 교통·도로민원 신속처리 기동단 |
| 화면 탭·목록 등 좁은 자리 | **교통·도로 기동단** |
| 금지 | `기동단`, `신속기동단`, `도로기동단` |

`교통·도로`까지가 최소 단위다. 이보다 줄이지 않는다. 기존 화면·데이터·시나리오의 표기를 전부 교체한다.

## 1. 실제 업무 흐름

```
전화 접수(1833-4088) 또는 시민창구·당직 이관
        ↓
기동단 접수 등록
        ↓
현장 확인 및 민원 분류           ← 기동단이 직접 한다
        ↓
처리방안 안내  【접수 후 1시간 이내】  ← 시민과의 첫 약속
        ↓
관계 부서·기관 협력 처리
   즉시 24시간 / 단기 48시간 / 중장기 협의
        ↓
진행상황·결과 안내
```

**기동단은 처리 주체가 아니라 접수·분류·조율 주체다.** 실제 조치는 소관 부서·기관이 한다. 현재 구현은 기동단이 직접 처리하는 전제로 되어 있어 협력 단계가 빠져 있다.

---

## 2. 처리구분 【현재 값이 전부 틀림】

| 구분 | 기한 | 대상 |
|---|---|---|
| **즉시** | **24시간** | 신호기 고장, 표지판·반사경 파손, BIS 오류 등 |
| **단기** | **48시간** | 시설물 파손, 정류장 시설 개선 등 |
| **중장기** | 관계기관 협의 (기한 미정) | 도로 혼잡, 신호체계 개선, 버스노선 개선 등 |

현재 구현은 즉시 4시간 · 단기 7일 · 중장기 6개월로 되어 있다. **전부 교체한다.**

중장기는 종료 기한이 없으므로 **경과일과 현재 단계**로 관리한다. 남은 시간을 표시하지 않는다.

---

## 3. 민원 유형 5분류

접수·분류·통계의 기준 축이다.

| # | 유형 | 세부 | 주 소관 |
|---|---|---|---|
| 1 | **도로 파손·침하** | 포트홀, 도로 침하, 보도 파손 | 도로과 / 구청 안전건설과 |
| 2 | **교통시설 고장·파손** | 신호기 고장, 표지판·반사경 파손, BIS 오류 | 교통정책과 · 대중교통과(BIS) |
| 3 | **불법주정차·통행 불편** | 불법주정차, 방치 PM, 무단방치 차량 | 주차물류과 / 구청 |
| 4 | **버스 이용 불편** | 무정차, 난폭운전, 배차간격, 정류장 시설 | **대중교통과 + 운수업체** |
| 5 | **교통체계 개선** | 도로 혼잡, 신호체계 개선, 버스노선 개선 | 교통정책과 (+경찰 협의) |

**4번 버스 민원은 처리 경로가 다르다.** 시설 조치가 아니라 **운수업체 확인·회신**을 거친다. 업체 통보 시각과 회신 시각을 별도로 기록한다. 현재 시스템에는 이 유형과 경로가 없다.

**5번은 대부분 중장기**이며 경찰 협의(교통안전시설 심의)가 필요한 건이 많다.

## 4. 화면 구성

### 4.1 상단 — 세 개의 시계

```
┌──────────────────────────────────────────────────────┐
│ 안내 대기 3건 ⏱ 최소 12분 남음   │ 즉시 5 │ 단기 8 │ 중장기 4 │
└──────────────────────────────────────────────────────┘
```

**「안내 대기」가 가장 왼쪽·가장 크게 온다.** 접수 후 1시간 이내 처리방안 안내가 기동단의 첫 약속이고, 24·48시간보다 먼저 오는 마감이기 때문이다.

- 남은 시간 20분 이하 주황, 10분 이하 적색, 초과 시 적색 배경 + 건수 강조
- 나머지 지표: 기한 임박 · 기한 초과 · 오늘 완료

### 4.2 본문 — 4열

| 열 | 내용 | 관리 기준 |
|---|---|---|
| **안내 대기** | 접수됐으나 처리방안 미안내 | **남은 시간(1시간 카운트다운)** |
| **즉시** | 24시간 | 남은 시간 |
| **단기** | 48시간 | 남은 시간 |
| **중장기** | 협의 진행 | 경과일 + 단계(5단계 중 몇) |

- 「안내 대기」 열이 비어 있는 것이 정상 상태다. 쌓이면 약속을 어기고 있다는 뜻이다.
- 분류 전 건은 안내 대기 열에만 있고, 분류하면 해당 열로 이동한다.

### 4.3 민원 카드

```
[유형색 바] 09:45  포트홀 · 도로 파손        [📷] [24시간]
            매송면 원평리 312 · #13670
            ⏱ 안내까지 12분 남음 · 접수 전화(1833-4088)
```

- 1줄: 시각 · 세부유형 · 대분류 · 사진 · 기한 배지
- 2줄: 위치 · 접수번호
- 3줄: **마감 시계** + 접수 경로
- 유형색은 5분류 기준. 기한은 배지로 구분(색을 두 축에 쓰지 않는다)

### 4.4 상세 (선택 시)

| 구획 | 내용 |
|---|---|
| 접수 | 시각 · 경로(전화/창구/이관) · 신고 내용 · 사진 |
| **현장 확인** | 확인자 · 시각 · 사진 · 판정 결과 → 이 단계에서 분류 확정 |
| **처리방안 안내** | 안내 시각 · 안내 내용 · 안내 방법(전화/문자) · **1시간 준수 여부** |
| 협력 | 소관 부서 · 협력 기관 · 통보 시각 · 회신 시각 · 회신 내용 |
| 처리 | 조치 내용 · 전후 사진 · 완료 시각 |
| 결과 안내 | 시민 통보 시각 · 방법 |

버스 민원은 「협력」에 **운수업체명·통보·회신**이 필수 항목으로 붙는다.

## 5. 신규 기능

### 5.1 안내 마감 알림 【최우선】

- 접수 시각부터 60분 카운트다운 시작
- 잔여 20분·10분·0분에 화면 상단 알림
- 초과 건은 「안내 대기」 열 최상단에 적색 고정
- 통계에 **1시간 준수율**을 지표로 둔다. 이것이 기동단의 핵심 성과 지표다

### 5.2 전화 접수 창구

- 대표전화 **1833-4088** 접수 건을 위한 빠른 등록 화면
- 통화 중 입력을 전제로 필드를 최소화: 유형 5개 버튼 → 위치 → 내용
- 기존 AI 접수 서기(자유 기록 → 구조화)를 그대로 재사용한다
- 접수 완료 시 **안내 마감 시각을 즉시 표시**해 상담원이 약속을 인지하게 한다

### 5.3 현장 확인 단계

- 기동단이 현장을 확인하고 분류를 확정하는 단계를 명시적으로 둔다
- 확인 사진·판정 결과를 기록하고, 이때 처리구분이 바뀔 수 있다
- 확인 전에는 「미분류」 상태로 안내 대기 열에 머문다

### 5.4 협력 기관 관리

- 소관 부서 외에 **협력 기관**을 별도 항목으로: 경찰서, 운수업체, 한국도로공사, 한국전력 등
- 통보 시각·회신 시각·회신 내용을 기록
- 회신 지연 건을 별도로 볼 수 있게 한다

## 7. 다른 화면과의 관계

| 화면 | 분류 축 |
|---|---|
| 당직 상황판 `#duty` | 긴급 / 일반 / 처리중 |
| **교통·도로 기동단 `#road`** | **안내대기 / 즉시 / 단기 / 중장기** |

두 축을 섞지 않는다. 도로교통 민원이 상황판에 들어오면 **기동단으로 이관**하고, 상황판 목록에서는 「기동단 이관」 표시만 남긴다.

시민 처리현황(`#track`)에서 기동단 민원은:
- 안내 전 — `1시간 이내에 처리 방향을 알려드립니다`
- 안내 후 — 안내 내용 + 처리구분별 예정 시각
- 중장기 — 5단계 진행 표시

## 9. 우선순위

운영이 9월 7일 시작이므로 아래 순으로 처리한다.

| 순위 | 항목 | 이유 |
|---|---|---|
| 1 | 처리기한 값 교체 (24h·48h·협의) | 현재 값이 틀려서 그대로는 못 쓴다 |
| 2 | 안내 대기 열 + 1시간 카운트다운 | 시민과의 첫 약속 |
| 3 | 명칭 통일 | 대외 노출 문구 |

| 5 | 전화 접수 화면 | 주 접수 경로 |
| 6 | 현장 확인 단계 | 분류 확정 절차 |
| 7 | 협력 기관·버스 민원 경로 | 유형 4·5의 실제 처리 |
